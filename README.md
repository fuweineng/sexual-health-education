# 性健康科普

一个独立的中文性健康科普站点，使用 Astro 构建。

## 项目原则

- 文案、页面结构和视觉设计均为本项目独立创作。
- 不复制 KnowSex 或其他站点的文章、代码、图片、Logo 与页面结构。
- 涉及健康的内容只做一般科普，不替代医生诊断或个体化治疗建议。
- 不设置广告、捐赠、付费墙或商业推广。
- 参考公共卫生机构和专业医学机构公开资料，并在文章末尾标注来源名称。

## 开发

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
corepack pnpm preview
```

正式站点地址为 `https://sex.unknow.one`。发布或更新文章前，请再次核对参考资料的版本与适用范围。
